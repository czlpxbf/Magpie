- 说明：三板块条目均为 checkbox，提出时记入、落地即勾选；CHANGELOG 于发版时从
  本文件已勾选条目生成（见 AGENTS.md 发版清单），本文件只记需求与验收，不写实现细节

## Added（新增）

- [x] 统一截图工具（2026-11-01 用户需求）：一个快捷键进入截图模式——拖选区域后
  选区旁浮出动作条，直接选「复制图片 / 提取文字 / 翻译 / 钉图」，不再按用途分拆
  多个快捷键。复制图片写入剪贴板可直接粘贴；提取文字沿用现有识别结果窗并保留
  原图供钉图；翻译按默认翻译服务直接出结果；钉图沿用现有钉图窗口。
  验收：按一次快捷键，框选任意区域，动作条出现四个动作；四者均可用且结果正确
- [x] 框选增强（2026-11-01）：松开鼠标后可拖动选区的边框/角点微调，也可点击
  空白处重新框选；拖选时选区边缘自动吸附窗口边缘与文字块边缘；Esc 取消、
  Enter 或双击选区内直接复制图片。验收：差几像素不必重来；靠近窗口/文字边缘时选框会被吸附
- [x] 识别前图像增强（2026-11-01）：识别前对小图做适度放大（最高 3x）并轻微锐化，
  提升小字、中英混排的识别率；大图不放大，避免无谓耗时。验收：小字号/高分屏截图识别结果明显更完整
- [x] 截图失败自动重截（迁移自 v0.1.18 未完成项）：首次识别为空时按框选矩形
  延迟静默重截（无遮罩、画面已稳）再识别，成功即正常出结果；仍空才报错并留证。
  验收：快速框选不再弹「未检测到文字」；用户日志可见「重截自愈成功」

## Changed（变更）

- [x] 截图快捷键合并（2026-11-01）：设置页「识图翻译 / 识图解释 / 识图总结」
  三个快捷键并入单一「截图」快捷键，翻译/解释/总结改为选区动作条内的动作；
  托盘菜单同步合并。旧配置文件的对应字段保留读取兼容，但不再注册。
  验收：设置页只剩「截图」与「访达选图取字」；托盘菜单不再列出四个识图入口
- [x] 截图入口交互（2026-11-01）：macOS 由系统 `screencapture -i` 改为应用内
  自绘遮罩框选（与 Windows 同一套前端），以保证选区后能显示动作条；
  框选期间静音划词捕获管线不变。v1 遮罩铺满光标所在屏（跨屏框选留待后续）。
  验收：macOS 截图模式无系统快门声、无系统选区框，遮罩与动作条均为应用内绘制
