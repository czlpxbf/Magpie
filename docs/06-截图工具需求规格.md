# 截图工具需求规格

- 状态：待用户确认（2026-11-02）
- 范围：截图工具（统一截图入口 + 框选动作 + 稳定性 + 品牌命名 + 构建交付）
- 关联：[release-v0.1.19](release/release-v0.1.19.md)、[docs/02 架构设计](02-架构设计.md)、[docs/03 模块设计](03-模块设计.md)
- 说明：本文件记录「用户当前要什么、做到什么程度算完成」，不写实现细节；实现方案属于
  docs/02、docs/03 与代码注释

## 1. 背景与目标

截图取词/翻译原先按用途拆成多个快捷键，用户需要先判断用途再按对应键；本轮改为
**一个截图入口，框选后就地选动作**。同时，首轮真机测试暴露了全屏遮罩的稳定性问题：
遮罩可能吞掉全部鼠标点击、Esc/右键取消后应用卡死、取消后无法再次截图、可同时打开
多个遮罩。本轮目标是把截图工具做成「随时可按、随时可退、不会卡住系统」的可靠工具，
并解决与 `yetone/magpie` 的名称/图标撞车。

## 2. 功能需求

### FR-1 统一入口

- 一个全局快捷键（默认 `Alt+S`，可在设置中修改）进入截图模式。
- 同一入口同时服务托盘菜单；托盘菜单不再单列「识图翻译 / 识图解释 / 识图总结」。
- 「访达选图取字」保留独立快捷键，不与截图入口合并。
- 旧配置文件中已废弃的识图快捷键字段继续读取兼容，但不再注册。
- 验收：设置页只剩「截图」与「访达选图取字」；按一次 `Alt+S` 即进入遮罩。

### FR-2 框选与微调

- 进入截图模式后显示冻结的整屏图（冻结瞬间画面），遮罩铺满光标所在显示器。
- 按住拖动框选；松开后可直接拖动选区整体、拖动边/角点微调。
- 点击选区外空白处重新框选；点击选区内部不重选。
- 吸附：拖选/微调时边缘吸附窗口边界与文字行边界；文字矩形由后台识别异步补齐，
  未就绪时至少吸附屏幕边缘与窗口边缘。
- 键盘：`Esc` 取消；`Enter` 或双击选区内复制图片。
- 验收：差几像素不必重来；靠近窗口/文字边缘时选框自动贴合。

### FR-3 动作条

框选完成后在选区旁浮出动作条，包含四个动作：

| 动作 | 行为 | 验收 |
|---|---|---|
| 复制图片 | 选区裁剪为图片写入系统剪贴板，可直接粘贴 | 粘贴出的图片与选区一致 |
| 提取文字 | 走现有 OCR 结果窗；保留原图供后续钉图 | 结果窗出现，文字可复制/继续动作 |
| 翻译 | OCR 后用默认翻译服务直接出译文 | 结果窗出现译文 |
| 钉图 | 沿用现有钉图窗口，贴到屏幕原位置附近 | 钉图窗口出现且可拖动/关闭 |

- 动作条优先放在选区下方；空间不足时翻到上方；水平居中并做屏幕边界钳制。
- 动作条出现后，鼠标可直接点选；动作执行后关闭遮罩。
- 验收：四个动作都可用，结果正确；动作条不超出屏幕。

### FR-4 识别增强与失败恢复

- 识别前对小图做适度放大（最高 3 倍）并轻微锐化；大图不放大，避免无谓耗时。
- 首次识别为空时，按选区矩形延迟静默重截（无遮罩、画面已稳）再识别；成功即正常
  出结果；仍为空才报错并保留截图证据。
- 验收：小字/中英混排识别更完整；快速框选不再轻易弹「未检测到文字」；日志可见
  「重截自愈成功」。

### FR-5 取消与退出

- `Esc`、右键、右上角关闭按钮、取消按钮均可退出截图模式。
- 取消后立即恢复桌面交互；应用保持响应。
- 取消后再次按 `Alt+S` 能正常进入截图模式。
- 验收：连续 10 次「进入 → Esc/右键取消」后，应用仍可正常截图和操作。

### FR-6 会话数量限制

- 同一时刻只允许一个截图遮罩/截图会话。
- 遮罩存在期间重复按快捷键应被忽略，不叠出第二个遮罩、不产生第二套截图数据。
- 取消或动作完成后，下一次快捷键才可开启新会话。
- 钉图窗口是否也限数：**待确认**（见第 7 节）。

## 3. 稳定性与体验需求（本轮反馈重点）

### NFR-1 绝不吞输入

- 全屏遮罩只有在冻结图渲染完成后才显示；空白/未加载状态绝不能留下透明置顶层。
- 页面加载失败时显示可见的错误页（含「关闭」按钮），不能只留一个透明窗口。
- 验收：任何异常路径下，屏幕都不会出现「看不见但点不动」的状态。

### NFR-2 取消不卡死

- 取消路径不得在 IPC 命令内同步销毁正在执行命令的 WebView。
- 遮罩置顶层不得拦截系统强制退出/菜单栏；用户始终有退出通道。
- 验收：Esc/右键取消后应用不转圈、不冻结；托盘、快捷键、其他窗口均可继续使用。

### NFR-3 异常自动兜底

- 遮罩创建后前端未就绪：最多 10 秒自动关闭并提示，不显示空白遮罩。
- 遮罩显示后完全收不到鼠标事件：最多 20 秒自动关闭并提示，避免永久卡住。
- 所有兜底路径都要释放捕获静音、清理临时截图、复位会话状态。
- 验收：模拟前端不加载/输入失效，等待上限时间后自动恢复桌面。

### NFR-4 可重复触发

- 会话状态（忙碌标志、静音守卫、临时文件、待处理任务）在取消/动作完成/异常退出时
  必须全部复位。
- 不允许出现「只有第一次能截图」的状态残留。
- 验收：连续 10 次成功/取消交替，行为一致。

### NFR-5 可观测

- 启动、前端就绪、取消、超时、识别重截等关键节点写入用户日志 `magpie.log`。
- 日志不记录截图内容/识别文字等敏感数据，只记录状态与尺寸/路径等诊断信息。
- 验收：卡住/失败时能从日志定位到「未就绪 / 无输入 / 取消」阶段。

## 4. 品牌与命名需求

### BR-1 与 yetone/magpie 区分

- 现状：GitHub 上存在另一个活跃项目 `yetone/magpie`（Go 写的菜单栏 AI 网关），
  其图标也是黑色喜鹊；用户安装后产生混淆。
- 目标：对外可见的名称、图标与本项目功能定位一致，且不与上述项目混淆。
- 约束：`bundle identifier` 变更会导致配置/更新路径断档；本轮建议保持不变。

### BR-2 对外名称

- 推荐显示名使用中文「拾趣」；英文内部代号可保留 Magpie，但 Finder/安装包/关于页
  显示名不得再是裸 `Magpie` 而与其他项目混淆。
- 待确认：是否接受「拾趣」作为唯一对外名称，或另取一个英文名。

### BR-3 图标

- 新图标不得继续使用「黑色喜鹊站在树枝上」的构图，避免与 yetone/magpie 视觉重合。
- 方向待确认：可围绕「选中的文字 / 光标 / 拾取」做非鸟类图形，保持现有蓝黑配色。
- 验收：Dock、菜单栏、关于页、安装包图标一致；与 yetone/magpie 并排可一眼区分。

## 5. 构建与交付需求

### REL-1 构建方式

- 使用仓库内 `.github/workflows/release.yml` 在 GitHub Actions 构建，不在本地出包为准。
- 触发方式：Actions 页手动 `Run workflow`，或推送 `v*` 标签自动构建。
- 构建提交必须是已推送的远端提交，产物对应明确 commit，便于回溯。

### REL-2 产物

- macOS：Universal 2 `.dmg`（Apple Silicon + Intel）。
- Windows x64：NSIS `-setup.exe` 与 `.msi`。
- 验收：两个平台构建成功；产物可安装、可启动。

### REL-3 版本与记录

- 测试包版本号与正式发版号区分清楚；当前仓库版本仍是 `0.1.18`，下一发版为
  `0.1.19`（见 release 文件）。
- 正式发版时按 AGENTS.md 三处同步版本号，并从 release 文件已勾选条目生成 CHANGELOG。
- 验收：安装包文件名/关于页版本与预期一致，不出现「测试包和旧包同名分不清」。

## 6. 验收清单（真机）

- [ ] `Alt+S` 进入截图，遮罩覆盖菜单栏/Dock，无系统快门声与系统选区框
- [ ] 拖选 → 松开 → 动作条出现，四个动作逐一验证
- [ ] 选区拖动/边角微调/空白重选/窗口与文字吸附
- [ ] `Esc` 取消、右键取消、右上角关闭；取消后应用立即可用
- [ ] 连续 10 次进入/取消，仍能正常截图
- [ ] 快速连按 `Alt+S` 10 次，只出现一个遮罩
- [ ] 前端加载失败/输入失效场景下，遮罩按时自动关闭并提示
- [ ] 失败场景日志可在 `magpie.log` 中定位
- [ ] macOS 与 Windows 安装包均由 Actions 构建成功
- [ ] 品牌改名/换图标后，Dock、菜单栏、关于页、安装包显示一致

## 7. 待确认项

1. **「同时打开的数量」范围**：仅限制截图遮罩为单例，钉图仍可多开（推荐，符合对照/
   拼图场景）；还是钉图也限制最多 N 个？若限，请给数值。
2. **对外名称**：只把显示名改为「拾趣」并保留 `bundle id`，还是连英文产品名、
   安装包名一起改？后者需要迁移配置/更新路径。
3. **图标方向**：是否接受非鸟类图形（文字/光标/拾取意象）？需要提供或让我出方案。
4. **Windows 真机验证**：当前只在 CI 完成编译/打包，是否需要在 Windows 真机上补一轮
   截图交互验收？
5. **跨屏框选**：本期仍只支持光标所在屏；是否列入下一期？

## 8. 本期不做

- 跨显示器框选、滚动截图、长截图
- 截图标注/马赛克/画笔
- 截图历史与云同步
- 多个截图遮罩并发
- 识图翻译/解释/总结作为独立快捷键入口
