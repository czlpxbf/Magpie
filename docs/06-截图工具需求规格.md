# 截图工具：Esc/右键取消后卡死，第二次无法触发

> 可直接作为 GitHub issue 正文。
> 本文描述的是**本项目二改前的状态**，不包含二改后的修复；构建/发布流程不在本 issue 讨论。

## 我的使用背景

我原来要记四个截图快捷键（识图取字、翻译、解释、总结），所以提出把截图收成一个入口：
按 `Alt+S` 框选，选区旁出现「复制图片 / 提取文字 / 翻译 / 钉图」四个动作。功能本身已经
能做，但我现在遇到的问题让它没法日常用。

## 二改前我遇到的现象

1. 第一次按 `Alt+S` 能正常进入截图，也能框选。
2. 我按 `Esc` 取消，或者点右键取消，**整个应用直接卡死**，转圈、没有响应。
3. 卡死后再按 `Alt+S`，快捷键没有任何反应，只能强制退出应用。
4. 同时打开的数量没有限制：我连按 `Alt+S`，会担心/出现多个遮罩，而不是只保留一个。
5. 第一次装机时还出现过按完快捷键所有窗口都点不动、只能长按电源键关机的情况；我理解
   这是同一类「全屏遮罩吞掉输入」的问题。

## 复现步骤

1. 在 macOS 上安装二改前的测试包，启动应用。
2. 按 `Alt+S`，确认遮罩出现，随便框选一块区域。
3. 按 `Esc` 取消（或点右键取消）。
4. 观察：应用卡死，无法再响应快捷键；再按 `Alt+S` 没有反应。
5. 重新启动应用后，快速连按 `Alt+S` 多次，观察遮罩数量。

## 我希望的行为

### P0：先保证不卡死

- `Esc`、右键、右上角关闭按钮都能立即退出截图，退出后应用保持响应。
- 取消后可以再次按 `Alt+S` 正常截图，不能出现“只有第一次能用”。
- 同一时刻只允许一个截图遮罩；连按多次也只出现一个。
- 遮罩没准备好时不要显示；加载失败时给我一个看得见、点得动的错误页，不能留透明窗口
  吞点击。
- 异常时能自己退出：页面未就绪最多 10 秒、遮罩显示后完全没有鼠标响应最多 20 秒，
  自动关闭并提示，不要让我强制关机。

### P1：保留已有的截图能力

- 框选后仍能拖动选区、拖边角微调、点空白处重选、吸附窗口/文字边缘。
- 四个动作仍然可用：复制图片、提取文字、翻译、钉图。
- 小字识别有增强；第一次识别为空时自动重截一次再判断。
- `Enter` 或双击选区内复制图片；`Esc` 取消。

## 验收标准

- [ ] `Alt+S` 进入截图，遮罩盖住菜单栏和 Dock，无系统选区框
- [ ] `Esc` 取消、右键取消、右上角关闭，应用每次都保持响应
- [ ] 连续 10 次「进入 → 取消」，每次都能再次正常截图
- [ ] 快速连按 `Alt+S` 10 次，只出现一个遮罩
- [ ] 取消后托盘、快捷键、其它窗口都能继续使用
- [ ] 故意制造加载失败/无响应，10 秒/20 秒兜底能自动关掉并提示
- [ ] 日志里能看到「就绪 / 取消 / 超时」节点，方便定位
