# 我的截图工具需求

- 状态：我的需求原稿（2026-11-02），确认后作为实现和验收依据
- 我的角色：每天用拾趣划词、截图取字、翻译的普通使用者
- 关联：[release-v0.1.19](release/release-v0.1.19.md)、[docs/02 架构设计](02-架构设计.md)、[docs/03 模块设计](03-模块设计.md)

## 0. 我为什么提这些

我原来要记好几个截图快捷键：识图取字一个、翻译一个、解释一个、总结一个，每次还得先想
“我这次要干嘛”。所以我提出把截图收成一个入口，框完直接选动作。

但装了我这版之后，我先遇到的是更严重的问题：

- 第一次装完，我按 `Alt+S`，整个电脑的窗口都点不动了，`Esc`、强制退出都不行，最后只能
  长按电源键关机。
- 第二次装完，第一次截图能出来，但我按 `Esc` 或右键取消后，软件直接卡死，再按快捷键
  也没反应。
- 同时打开的数量也没有限制，我连按会担心叠出多个遮罩。
- 图标和 GitHub 上的 `yetone/magpie` 撞脸，我一开始还以为装错软件了。

所以我现在要的不只是“功能有”，而是：**随时能按、随时能退、绝不把我电脑卡住**。功能可以
后面加，稳定性必须先过关。

## 1. 我要的截图方式

### 1.1 一个入口

- 我只想记住一个键：默认 `Alt+S`，设置里可以改。
- 托盘菜单也用同一个入口，不要再单列“识图翻译 / 识图解释 / 识图总结”。
- “访达选图取字”我还是想保留独立快捷键，它和截图不是一件事。
- 旧配置里那些废弃的识图快捷键字段，读旧配置时可以保留，但不要再注册、不要再出现在
  设置页和托盘里。

验收：我打开设置，只看到“截图”和“访达选图取字”两个相关入口；按一次 `Alt+S` 就进入
截图。

### 1.2 框选后直接选动作

框选完，我要在选区旁边看到动作条，而不是先复制再去别的地方找功能。四个动作缺一不可：

| 我要的动作 | 我希望发生什么 | 我怎么验收 |
|---|---|---|
| 复制图片 | 把我框的那块图放进剪贴板，我直接 `Cmd+V` 就能粘贴 | 粘贴出来的图和框选区域一致 |
| 提取文字 | 打开现在的识别结果窗，文字能复制、能继续操作 | 结果窗出现，文字正确 |
| 翻译 | 用我设置的默认翻译服务直接出译文 | 结果窗出现译文 |
| 钉图 | 把我框的图钉在屏幕上，能拖动、能关掉 | 钉图窗口出现在原位置附近 |

- 动作条优先出现在选区下方；下面放不下就翻到上面；不能超出屏幕。
- 动作做完，遮罩要自己关掉，不要留在屏幕上。

验收：四个动作我各点一次，都能正确完成，动作条不跑出屏幕。

## 2. 框选时的手感

- 我按下快捷键后，看到的是**按下那一刻的冻结画面**，不是还在动的桌面；不要系统自带的
  选区框，也不要有快门声。
- 遮罩要盖住菜单栏和 Dock，不然我想框顶部/底部时会漏出去。
- 框错了不要让我重来：松开后我能拖动整个选区，也能拖边和角微调。
- 点选区外面的空白处，我要能重新框；点选区里面不要莫名其妙地重选。
- 靠近窗口边缘或文字行时，选框要自动吸附，差几个像素不用我硬拖。
- 键盘要能用：`Esc` 取消；`Enter` 或双击选区内直接复制图片。
- 这版先只支持光标所在的那块屏幕；跨屏框选我接受下一期再做。

验收：我框一条文字、一个按钮、一个窗口边缘，都能一次框准；差几像素时能拖角微调；
按 `Esc` 能退出。

## 3. 识别

- 小字、高分屏上的小字，识别前要放大一点、锐化一点，别让我截了半天还是识别不出来。
- 第一次没识别到文字时，不要立刻弹“未检测到文字”。先按我框的区域静默重截一次、再识别；
  成功了就正常出结果，还是空才报错。
- 报错时把截图留在日志/临时目录里，方便排查；不要删掉证据。
- 验收：小字和中英混排比以前完整；快速框选不会动不动就报空。

## 4. 我的稳定性底线（P0）

这部分比功能更重要。如果只能先做一部分，先保证下面这些。

### 4.1 不许吞点击

- 截图窗口没准备好，就不要把它显示出来；我不要看到“桌面看起来正常，但所有窗口都点不动”。
- 万一加载失败，要给我一个看得见、点得动的错误页，上面有“关闭”按钮；不能只留一个
  透明的全屏窗口。
- 任何情况下，都不能出现“看不见但点不动”的状态。

### 4.2 取消不能卡死

- `Esc`、右键、右上角关闭按钮、错误页的“关闭”，都要能退出截图。
- 退出后软件要立刻恢复响应：托盘、快捷键、其他窗口都能继续用。
- 不要出现“遮罩关了，但软件还在转圈”的情况。

### 4.3 取消后还能再截图

- 我取消一次后，再按 `Alt+S` 必须还能正常截图。
- 我不要“只有第一次能用”的截图工具。
- 验收：我连续做 10 次“进入 → 取消”，每次都能正常进入和退出。

### 4.4 同时只能有一个截图遮罩

- 我连按 `Alt+S`，只应该出现一个遮罩；不能叠出第二个，也不能同时存在两套截图数据。
- 上一个遮罩取消或动作完成后，下一次才能开新的。
- 验收：我快速连按 10 次，屏幕上只有一个遮罩；取消后再按，正常出现一个。
- 钉图窗口要不要也限数量，我还没想好；先按“截图遮罩单例、钉图可多开”做。

### 4.5 异常要自己退出

- 如果页面没加载出来，最多等 10 秒就自己关掉，并告诉我“截图界面未加载，请重试”。
- 如果遮罩显示了但完全没有鼠标响应，最多等 20 秒就自己关掉，不要让我强制关机。
- 自动退出时要把捕获静音、临时截图、会话状态都清干净，不能影响下一次截图。

### 4.6 出问题我要能查

- 启动、准备好、取消、超时、重截这些节点，要写进 `magpie.log`。
- 日志不要记录我截到的文字内容，只记状态、尺寸、路径这类排查信息。
- 我卡住时，能通过日志看出是“没准备好”“没输入”还是“取消”阶段。

## 5. 名字和图标

- 我不想和 `yetone/magpie` 混在一起。它也是菜单栏里一个黑喜鹊图标的应用，我装完后
  第一反应是“图标怎么不对劲”。
- 我的要求：
  - 对外显示名至少改成「拾趣」；Finder、关于页、安装包名字不要只写裸 `Magpie`。
  - 图标不要继续用“黑喜鹊站在树枝上”的构图，我要能一眼和 yetone 的区分开。
  - `bundle id` 先不要动，避免我的设置、日志、更新路径断掉。
- 英文产品名、安装包名要不要一起改，图标具体画成什么样，我需要先看方案再定。

## 6. 构建和交付

- 我不想在本地编译，也不想每次都让你手动折腾。我要用 GitHub Actions 出包：
  - macOS：Universal 2 的 `.dmg`（Apple Silicon + Intel 都能装）。
  - Windows x64：`-setup.exe` 和 `.msi`。
- 每次测试包要能对应到明确的提交，我拿到包能知道是哪一版。
- 测试包和正式包不要同名、同版本号，不然我分不清哪个是新修的。
- 正式发版按项目规则同步版本号、生成 CHANGELOG。

## 7. 我会怎么验收

我会按下面的顺序试，不通过就不算完成：

- [ ] 退出旧版，安装新包，确认 Dock、菜单栏、关于页名字和图标一致
- [ ] 按 `Alt+S`，遮罩盖住菜单栏和 Dock，无快门声、无系统选区框
- [ ] 拖选文字/按钮/窗口边缘，检查吸附和边角微调
- [ ] 四个动作逐一验证：复制图片、提取文字、翻译、钉图
- [ ] `Esc` 取消、右键取消、右上角关闭，取消后软件立即可用
- [ ] 连续 10 次进入/取消，仍能正常截图
- [ ] 快速连按 `Alt+S` 10 次，只出现一个遮罩
- [ ] 故意制造加载失败/无响应，确认 10 秒/20 秒兜底能自动关掉并提示
- [ ] 看 `magpie.log`，能对应上刚才发生的事
- [ ] 在 macOS 和 Windows 上各装一次，确认安装包能启动

## 8. 还要我拍板的事

1. **“同时打开数量”的范围**：我现在倾向“截图遮罩只允许一个，钉图允许多开”。如果
   钉图也要限，我会给具体数字。
2. **名字改到什么程度**：先只改显示名「拾趣」、保留 `bundle id`，还是连英文名和安装包名
   一起改？后者要接受配置/更新路径迁移。
3. **图标方向**：我可以接受非鸟图形（文字、光标、拾取这类意象），但要先看一版方案。
4. **Windows 真机**：如果我有 Windows 机器就补一轮；没有就先用 CI 构建 + 你在 Windows
   上帮我验。
5. **跨屏框选**：这期先不做，下一期再排。

## 9. 这期先不要

- 跨显示器框选、滚动截图、长截图
- 截图标注、马赛克、画笔
- 截图历史和云同步
- 多个截图遮罩同时存在
- 识图翻译/解释/总结再做成独立快捷键

## 10. 我的优先级

如果时间有限，我按这个顺序要：

1. **P0**：不吞点击、不卡死、取消后能再截、同时只有一个遮罩
2. **P1**：四个动作可用、框选和吸附顺手、识别增强与失败重截
3. **P2**：品牌改名/换图标、Windows 真机验收、跨屏框选

先让我敢每天按 `Alt+S`，再谈其它。
