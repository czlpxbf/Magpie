# 我的截图工具需求

- 状态：我的需求清单（第一人称）
- 说明：这里只写我要什么，不写 bug 报告、不写“二改前状态”、不写构建/发布流程

## 1. 我只要一个截图入口

- 我只想记住一个快捷键：默认 `Alt+S`，设置里可以改。
- 托盘菜单和设置页也只留“截图”和“访达选图取字”，不要再列“识图翻译 / 识图解释 /
  识图总结”。
- 旧配置里那些识图快捷键字段可以继续读，但不要再注册、不要再出现在界面上。

## 2. 按下快捷键后，我要这样框选

- 我看到的是按下那一刻的冻结画面，不是还在动的桌面。
- 不要系统自带的选区框，也不要有快门声。
- 遮罩要盖住菜单栏和 Dock，框顶部/底部时不能漏出去。
- 按住拖动框选；松开后能拖动整个选区，也能拖边和角微调。
- 点选区外面空白处可以重新框；点选区里面不要重选。
- 靠近窗口边缘或文字行时，选框要自动吸附，差几个像素不用我硬拖。
- `Esc` 取消；`Enter` 或双击选区内直接复制图片。
- 动作条优先放在选区下方，放不下翻到上方，不能超出屏幕。
- 这版先只支持光标所在的那块屏幕，跨屏以后再说。

## 3. 框选后我要四个动作

| 我要的动作 | 我要的结果 |
|---|---|
| 复制图片 | 框选区域进剪贴板，我直接粘贴就能用 |
| 提取文字 | 打开现有识别结果窗，文字能复制、能继续操作 |
| 翻译 | 用我设置的默认翻译服务直接出译文 |
| 钉图 | 把框选的图钉在屏幕上，能拖动、能关掉 |

动作做完，遮罩要自己关掉，不要留在屏幕上。

## 4. 识别要尽量一次成功

- 小字、高分屏的小字，识别前要放大一点、锐化一点。
- 第一次没识别到文字时，不要马上报“未检测到文字”；先按我框的区域静默重截一次再识别，
  成功了就正常出结果，还是空才报错。
- 报错时保留截图证据，方便排查。

## 5. 稳定性和数量限制（最优先）

这部分是我最在意的，功能可以少做，但这些必须做到：

- **截图窗口/会话只能有一个，明确禁止二开。** 二开会卡死，所以必须从设计上限制数量，
  不能靠界面提示或事后补救。
- 我连按 `Alt+S`，只应该进入一次截图，不能叠出第二个遮罩、第二套截图数据。
- 上一个截图取消或动作完成后，窗口必须彻底释放，下一次 `Alt+S` 才能再开一个新的。
- 按 `Alt+S` 不允许让我所有窗口都点不动；遮罩必须始终能退出，不能出现只能长按电源键
  关机的情况。
- `Esc`、右键、右上角关闭按钮都要能取消；取消后应用不能卡死，托盘、快捷键、其它窗口
  都要继续能用。
- 取消后必须还能再截图，不能“只有第一次能用”。
- 遮罩没准备好就不要显示；加载失败要给我一个看得见、点得动的错误页，不能留一个透明
  全屏窗口吞点击。
- 异常时要自己退出：页面未就绪最多 10 秒、遮罩显示后完全没有鼠标响应最多 20 秒，
  自动关闭并提示，不要让我强制关机。

## 6. 名字和图标

- 我不想和 `yetone/magpie` 混在一起：它也是菜单栏里的黑喜鹊图标应用。
- 对外显示名至少改成「拾趣」；Finder、关于页、安装包名字不要只写裸 `Magpie`。
- 图标不要继续用“黑喜鹊站在树枝上”的构图，我要能一眼和 yetone 的区分开。
- `bundle id` 先不要动，避免我的设置、日志、更新路径断掉。
- 英文名、安装包名要不要一起改，图标具体画成什么样，我看方案后再定。

## 7. 我会这样验收

- [ ] 按 `Alt+S`，遮罩盖住菜单栏和 Dock，无系统选区框
- [ ] 框选文字/按钮/窗口边缘，能吸附，也能拖边角微调
- [ ] 四个动作逐一验证：复制图片、提取文字、翻译、钉图
- [ ] `Esc` 取消、右键取消、右上角关闭，取消后应用立即可用
- [ ] 连续 10 次进入/取消，每次都能再次正常截图
- [ ] 快速连按 `Alt+S` 10 次，只出现一个截图窗口
- [ ] 故意制造加载失败/无响应，遮罩能按 10 秒/20 秒兜底自动关掉
- [ ] 名字、图标在 Dock、菜单栏、关于页、安装包里保持一致

## 8. 这期先不要

- 跨显示器框选、滚动截图、长截图
- 截图标注、马赛克、画笔
- 截图历史和云同步
- 多个截图遮罩同时存在
- 识图翻译/解释/总结再做成独立快捷键

## 9. 我的优先级

1. **P0**：禁止二开、不吞点击、不卡死、取消后能再截
2. **P1**：四个动作可用、框选和吸附顺手、识别增强
3. **P2**：名字/图标、跨屏框选

先让我敢每天按 `Alt+S`，再谈其它。
